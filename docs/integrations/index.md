# Integrations

Click-Dog exports query telemetry to OTLP-compatible backends and Splunk HEC.

Use [Datadog](datadog.md) when you want the packaged experience: dashboard
provisioning, self-monitoring, and recommended monitors.

Use the backend pages below when you want the export wiring today and want to
register interest in packaged dashboards, saved views, or alert recipes:

- [Honeycomb](honeycomb.md)
- [Generic OTLP](generic-otlp.md)
- [Splunk HEC](splunk-hec.md)

The export path is deliberately backend-neutral. The packaged experience grows
where users tell us they need complete boards, queries, and production alerts.
